# Yuce GPS Location Alarm privacy policy

Public privacy policy for YuceRadius (`com.yuce.radius`), in English and Turkish.

Published URL: https://yusaacikalin.github.io/yuce-radius-privacy-policy/

`index.html` is a standalone, responsive document with no external scripts, fonts, analytics or ads. GitHub Pages publishes the root of `main`.

This repository contains only the privacy document, not the Android app source or user data.

Update the text and effective date whenever data processing changes. Keep the app and AdMob policy URLs in sync. Do not post personal data in public issues.
